# JobHunter Chrome Extension

1. Ekstrak `jobhunter-chrome-extension.zip`.
2. Buka `chrome://extensions` atau `edge://extensions`.
3. Aktifkan Developer mode, pilih Load unpacked, lalu pilih folder hasil ekstrak.
4. Buka lowongan Glints atau Jobstreet dan klik ikon JobHunter.

Ekstensi hanya membuka URL handoff ke JobHunter. Ekstensi tidak menyimpan token,
cookie, CV, atau data lowongan, dan tidak memanggil API penyimpanan JobHunter.
